# Content Dashboard

Dashboard de gestão de conteúdo para criadores digitais, com tema escuro e navegação entre seções.

## Tecnologias

- **Next.js 15** (App Router)
- **TypeScript 5**
- **Tailwind CSS 3**
- **shadcn/ui**
- **lucide-react**

## Seções

| Rota | Seção |
|---|---|
| `/dashboard` | Visão Geral |
| `/dashboard/instagram` | Instagram Manager |
| `/dashboard/analytics` | Analytics |
| `/dashboard/calendar` | Content Calendar |
| `/dashboard/competitors` | Competitor Tracker |
| `/dashboard/news` | News Consolidator |

## Como rodar

```bash
npm install
npm run dev
# Acesse http://localhost:3000
```
