## Dark Theme

The app is globally dark. The `<html>` element has `class="dark"` set in the root layout.

All colour values use CSS custom properties defined in `app/globals.css` under `:root`. Tailwind's `darkMode: ["class"]` strategy is used, but since dark is always on, the `:root` block contains the dark palette directly (no light/dark split needed unless a theme toggle is added later).

### Key design tokens

| Token | Purpose |
|---|---|
| `--background` | Page background (`hsl(224 71% 4%)`) |
| `--card` | Card surfaces — slightly lighter |
| `--sidebar` | Sidebar background — darkest surface |
| `--primary` | Accent purple (`hsl(263 90% 68%)`) |
| `--muted-foreground` | Secondary text |
| `--border` | Subtle borders |

## Component Conventions

### shadcn/ui
- Components live in `components/ui/`. They are **manually written** (not generated by CLI) because the project was scaffolded without Node.js installed.
- Each component follows the official shadcn/ui source exactly — `cva` for variants, `forwardRef`, `cn()` for class merging.
- To add more shadcn components, copy from [ui.shadcn.com](https://ui.shadcn.com/docs/components) and place them in `components/ui/`.

### Page components
- Pages are **Server Components** by default (no `"use client"` unless interactivity is needed).
- The Sidebar (`components/sidebar.tsx`) is a Client Component because it uses `usePathname()` for active link detection.
- All pages use a consistent layout: `<div className="space-y-8">` with a header block, stats row, and content area.

### Imports
- Use the `@/*` path alias (maps to the project root) for all internal imports.
- Icon imports always come from `lucide-react`.

## Key Decisions

1. **Route group `(dashboard)`** — wraps all dashboard routes in a shared layout with the sidebar without adding a URL segment.
2. **No theme toggle** — dark mode is unconditional. Adding a toggle later requires splitting `:root` into `:root` (light) and `.dark` (dark) blocks and adding a state provider.
3. **Manual shadcn scaffold** — Node.js was not available at project creation time, so `npx shadcn@latest init` was not used. All components were written by hand following the shadcn source.
4. **Placeholder data** — all section pages use static inline data. Replace with real API calls when backend is connected.
5. **No auth** — authentication is not implemented. Add middleware + a session provider when ready.

## Getting Started

```bash
# 1. Install dependencies (requires Node.js ≥ 18)
npm install

# 2. Start the dev server
npm run dev

# 3. Open http://localhost:3000
```

The root page (`/`) redirects immediately to `/dashboard`.
